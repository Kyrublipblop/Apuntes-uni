C++ se compone de diferentes tipos de símbolos o “tokens”.

Categoría Descripción Ejemplos

2. NOTACIÓN BNF (BACKUS-NAUR FORM)

Estándar formal para definir la sintaxis del lenguaje.

Metasímbolos BNF

  • ::= : Se define como.
  • | : Alternativa (O lógico).
  • { } : Repetición (0 o más veces).
  • [ ] : Opcional (0 o 1 vez).
  • < > : Símbolo no terminal (categoría sintáctica).
  • " " : Símbolo terminal (texto literal).

Reglas Sintácticas

  • Identificador: <identificador> ::= ( <letra> | "_" ) { <letra> | <digito> | "_" }
  • Sentencia If: <inst_if> ::= "if" "(" <condicion> ")" <instruccion> [ "else" <instruccion> ]

3. ARQUITECTURA Y EJECUCIÓN

Arquitectura del Computador (Modelo Von Neumann)

      +-------------------------------------------------------+
      |              UNIDAD CENTRAL DE PROCESO (CPU)          |
      |                                                       |
      |  +-----------------------+      +------------------+  |
      |  |          ALU          | <--> | UNIDAD CONTROL   |  |
      |  | (Cálculos y Lógica)   |      | (Coordina todo)  |  |
      |  +-----------------------+      +------------------+  |
      +--------------^----------------------------^-----------+
                     |                            |
              +------v----------------------------v------+
              |         MEMORIA PRINCIPAL (RAM)          |
              |     (Instrucciones y Datos actuales)     |
              +------^----------------------------^------+
                     |                            |
      +--------------v-------------+      +-------v--------------+
      |    PERIFÉRICOS ENTRADA     |      |  PERIFÉRICOS SALIDA  |
      | (Teclado, Ratón, Cámara)   |      |  (Monitor, Altavoz)  |
      +----------------------------+      +----------------------+

Tabla: Ejecución Interpretada vs. Compilada

Característica Ejecución Interpretada Ejecución con Compilación (C++)
Proceso Traduce y ejecuta línea a línea. Traduce todo el código a binario antes.
Velocidad Más lenta (traducción en tiempo real). Muy rápida (ejecución directa).
Detección errores En tiempo de ejecución. Antes de ejecutar (en la fase de compilación).

4. PROGRAMACIÓN C++ Y CUADRO ANTI-ERRORES

Ejemplo de Programa Completo

#include <iostream> // Directiva de entrada/salida
using namespace std; // Espacio de nombres

int main() {        // Inicio del programa
    int a, b, res;  // Identificadores de variables

    cout << "Introduce dos numeros: ";
    cin >> a >> b;   // Entrada de datos

    res = a + b;     // La ALU realiza la suma

    cout << "El resultado es: " << res << endl;

    return 0;        // Fin del programa
}

Cuadro Anti-Errores de Sintaxis

Código INCORRECTO Código CORREGIDO Razón del Error
int mi variable; int mi_variable; Espacios prohibidos en identificadores.
cin << x; cin >> x; Dirección de flujo errónea (se usa >> para entrada).
cout << "Hola; cout << "Hola"; Falta cerrar la comilla del literal.
#include <iostream>; #include <iostream> Las directivas del preprocesador no llevan ;.
IF (x > 0) if (x > 0) C++ distingue mayúsculas/minúsculas (if debe ser minúscula).
