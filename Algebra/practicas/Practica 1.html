📐 2. PRODUCTO DE MATRICES

(m × n) · (n × p) = (m × p)

Las columnas de la primera matriz tienen que coincidir con las filas de la segunda.

Producto ¿Se puede? Resultado
2×3 · 3×2 ✅ Sí 2×2
3×2 · 2×3 ✅ Sí 3×3
2×3 · 2×3 ❌ No Dimensiones incompatibles
IMPORTANTE: A·B ≠ B·A en general.

🚨 6. ROUCHÉ-FROBENIUS

Sistema:

Ax = b

Matriz ampliada: 

Ab = A.augment(b)
Compatible ⇔ rg(A) = rg(A|b)
Condición Tipo Soluciones
rg(A) = rg(A|b) = n ✅ SCD Una única
rg(A) = rg(A|b) < n ♾️ SCI Infinitas
rg(A) < rg(A|b) ❌ SI Ninguna
n = número de incógnitas = número de columnas de A.

🧮 7. ELIMINACIÓN DE GAUSS

Objetivo

(A | b) → matriz triangular → solución

Operaciones elementales permitidas

  • Intercambiar dos filas.
  • Multiplicar una fila por un número distinto de 0.
  • Sumar a una fila un múltiplo de otra.

Comandos Sage

# Fi ← Fi + t·Fj

Ab = Ab.with_added_multiple_of_row(i,j,t)


# Fi ← t·Fi

Ab = Ab.with_rescaled_row(i,t)


# Intercambiar filas

Ab.swap_rows(i,j)
Índices: fila matemática 1 → Sage 0
fila matemática 2 → Sage 1
fila matemática 3 → Sage 2

🎯 8. ¿QUÉ NÚMERO PONGO PARA HACER UN CERO?

t = − elemento / pivote

Si quieres eliminar un 3 y el pivote es 2: 

t = -3/2

Entonces: 

Fi ← Fi + (-3/2)Fj

En Sage: 

Ab = Ab.with_added_multiple_of_row(i,j,-3/2)

A = matrix(QQ, [

🔄 10. GAUSS-JORDAN

(A | b) → (I | x)

Diferencia:

Gauss Gauss-Jordan
Ceros debajo de pivotes Ceros debajo Y encima
Termina en triangular Termina en identidad
Sustitución hacia atrás Solución directamente

Normalizar pivote

Ab = Ab.with_rescaled_row(i,1/pivote)

Eliminar

Ab = Ab.with_added_multiple_of_row(i,j,t)
Objetivo final: (A|b) → (I|x)

🔓 11. INVERSA MEDIANTE GAUSS-JORDAN

(A | I) → (I | A⁻¹)

Plantilla

n = A.nrows()

AI = A.augment(
    identity_matrix(QQ,n)
)

# Aplicar Gauss-Jordan...

# Cuando:
# (I | A^-1)

Ainv = AI[:,n:]
Las mismas operaciones que convierten A en I convierten I en A⁻¹.

🧱 12. MATRICES ELEMENTALES

P · A = operación elemental aplicada a A
Matriz Operación
Pᵢⱼ(t) Fᵢ ← Fᵢ + tFⱼ
Pᵢ(t) Fᵢ ← tFᵢ
Pᵢⱼ Fᵢ ↔ Fⱼ
Todas se construyen a partir de la identidad Iₙ.

🛠️ 13. FUNCIONES PARA MATRICES ELEMENTALES

Fᵢ ← Fᵢ + tFⱼ

def pijt(n,i,j,t):
    P = identity_matrix(QQ,n)
    P[i,j] = t
    return P

Fᵢ ← tFᵢ

def pit(n,i,t):
    P = identity_matrix(QQ,n)
    P[i,i] = t
    return P

Intercambiar filas

def pij(n,i,j):
    P = identity_matrix(QQ,n)
    P.swap_rows(i,j)
    return P

🔁 14. GAUSS USANDO MATRICES ELEMENTALES

En lugar de modificar directamente una fila: 

Ab = Ab.with_added_multiple_of_row(1,0,-2)

podemos crear la matriz elemental: 

P = pijt(3,1,0,-2)

Ab = P * Ab
MUY IMPORTANTE:

P · A → operaciones sobre filas.
A · P → operaciones sobre columnas.

🧩 15. FUNCIÓN elimGauss3x3

def elimGauss3x3(A,b):

    Ab = A.augment(b)

    # Eliminar debajo del primer pivote
    t = -Ab[1,0]/Ab[0,0]
    Ab = Ab.with_added_multiple_of_row(1,0,t)

    t = -Ab[2,0]/Ab[0,0]
    Ab = Ab.with_added_multiple_of_row(2,0,t)

    # Eliminar debajo del segundo pivote
    t = -Ab[2,1]/Ab[1,1]
    Ab = Ab.with_added_multiple_of_row(2,1,t)

    # Sustitución hacia atrás
    x3 = Ab[2,3]/Ab[2,2]

    x2 = (
        Ab[1,3] - Ab[1,2]*x3
    ) / Ab[1,1]

    x1 = (
        Ab[0,3]
        - Ab[0,1]*x2
        - Ab[0,2]*x3
    ) / Ab[0,0]

    return vector([x1,x2,x3])
⚠️ Esta función es SIN PIVOTAJE.
Si aparece un pivote 0, hay que intercambiar filas.

🔢 16. GAUSS PARA CUALQUIER n×n

def elimGauss(A,b):

    n = A.nrows()

    Ab = A.augment(b)

    # Eliminación
    for k in range(n-1):

        for i in range(k+1,n):

            t = -Ab[i,k]/Ab[k,k]

            Ab = Ab.with_added_multiple_of_row(
                i,k,t
            )

    # Sustitución hacia atrás
    x = vector(QQ,n)

    for i in range(n-1,-1,-1):

        suma = 0

        for j in range(i+1,n):
            suma += Ab[i,j]*x[j]

        x[i] = (
            Ab[i,n]-suma
        ) / Ab[i,i]

    return x

🚨 19. ERRORES TÍPICOS DEL EXAMEN

❌ Índices
Sage empieza en 0.
❌ Dimensiones
Antes de A*B comprueba:
columnas A = filas B
❌ Fracciones
Usa QQ.
❌ Pivote 0
Hay que intercambiar filas.
❌ Gauss ≠ Gauss-Jordan
Gauss → triangular.
Gauss-Jordan → identidad.
❌ P·A vs A·P
P·A → filas.
A·P → columnas.
